# 🛒 TechKart Ecommerce Platform

A full-stack ecommerce web application built with Node.js, Express, MongoDB, and EJS.

Designed with scalable backend architecture, authentication systems, product management, and admin functionalities.

---

# ✨ Features

## 👤 Authentication
- User registration & login
- Session-based authentication
- Admin authorization
- Protected routes

## 🛍️ Ecommerce Features
- Product listing
- Product details page
- Cart system
- Order management
- Checkout workflow

## 🛠️ Admin Features
- Product management
- Order management
- User management
- Dashboard system

## ⚙️ Backend Architecture
- MVC pattern
- Middleware architecture
- Service layer structure
- Utility helpers
- Modular routes/controllers

# 🚀 Installation

Clone repository:

```bash
git clone your-repo-link
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm start
```
